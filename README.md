# 오늘한칸

노션에서 쓰던 개인 시스템을 웹앱으로 옮기는 프로젝트입니다.

## 현재 기능

- 로그인 / 회원가입 (Supabase Auth)
- PC · 모바일 같은 계정 데이터 동기화
- 집: 오늘 할일, 30분 단위 시간계획, 오늘 습관, 다가오는 일정, 오늘 대시보드
- 할일을 시간계획으로 드래그해서 배치
- 빈 시간대를 드래그해서 시간계획 생성
- 달력 월/주/일 보기
  - 월 보기에서 일정이 할일보다 먼저 표시
  - 일 보기에서 타임라인 / 목록 전환
- 할일별 시간추적 및 과거 기록
- 작업현황: 목표 / 작업 / 보류 / 완료
- 습관 템플릿
- 하루 기준 새벽 3시

## 데이터

Supabase 프로젝트 `when-did-i-do-it`의 Auth를 함께 사용합니다. 따라서 기존 ‘그거 언제 했더라’ 계정으로도 로그인할 수 있습니다.

오늘한칸 데이터는 별도 `onekan_state` 테이블에 저장되며 RLS로 각 사용자가 자기 데이터만 읽고 쓸 수 있습니다.

## GitHub Pages

`.github/workflows/pages.yml`이 `main` 브랜치 변경 시 GitHub Pages 배포를 시도합니다.

배포 주소: `https://greejiu.github.io/onekan/`

## 구조

- `index.html` — 화면 마크업
- `css/style.css` — 반응형 UI
- `js/supabase.js` — Supabase 연결
- `js/auth.js` — 로그인 / 회원가입 / 로그아웃
- `js/app.js` — 할일, 습관, 시간계획, 달력, 시간추적, 작업현황, 동기화
